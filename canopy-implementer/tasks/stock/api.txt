Package no.experis.stock.
record StockItem(String sku, int onHand); StockItem receive(int quantity) throws IllegalArgumentException when the quantity is not positive; StockItem reserve(int quantity) throws IllegalArgumentException when the quantity is not positive and IllegalStateException when more is reserved than is on hand; both return a new item. Responsibility: the quantity rules of one item: receiving, reserving and their rejections.
interface StockRepository: Optional<StockItem> findBySku(String sku); void save(StockItem item). class InMemoryStockRepository implements it, no-argument constructor. Responsibility: keeping and finding stock items by sku; saving an item again replaces the one with the same sku.
class StockService, constructor StockService(StockRepository): void receive(String sku, int quantity), which creates the item when the sku is new; void reserve(String sku, int quantity) throws IllegalArgumentException when there is no item for the sku; int available(String sku), which is 0 for an unknown sku. Responsibility: receiving and reserving per sku through the repository, an unknown sku, and the units available per sku.
