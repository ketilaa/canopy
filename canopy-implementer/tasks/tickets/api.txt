Package no.experis.tickets.
enum TicketStatus { ISSUED, VALIDATED, CANCELLED }. record Ticket(String id, LocalDateTime issuedAt, TicketStatus status); Ticket validate(LocalDateTime at) and Ticket cancel() return a new ticket and throw IllegalStateException. Responsibility: the state of one ticket: validating within 90 minutes of issuedAt, cancelling, and their rejections (expired, already validated, cancelled, a validated ticket cannot be cancelled); it knows nothing about other tickets or about unknown ids.
interface TicketRepository: Optional<Ticket> findById(String id); void save(Ticket ticket). class InMemoryTicketRepository implements it, no-argument constructor. Responsibility: keeping and finding tickets by id; saving a ticket again replaces the one with the same id.
class TicketService, constructor TicketService(TicketRepository): Ticket issue(String id, LocalDateTime at); Ticket validate(String id, LocalDateTime at); Ticket cancel(String id); an unknown id throws IllegalArgumentException. Responsibility: issuing tickets and validating and cancelling them by id through the repository; an unknown ticket.
